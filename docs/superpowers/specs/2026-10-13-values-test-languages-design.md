# Тест ценностей на шести языках — дизайн

**Дата:** 2026-10-13
**Статус:** дизайн согласован владельцем, план не написан
**Основа:** тест ценностей на русском — `docs/superpowers/specs/2026-10-12-values-test-design.md`
(раздел «Не входит: другие языки — следующим заходом») и план того же дня.
**Репозиторий:** `land_linkeon`.

## Задача

С 12.10.2026 на linkeon.io работает бесплатный тест ценностей Шварца — только
по-русски. Сайт выходит на семи языках. Нужно открыть тест на английском,
испанском, немецком, французском, португальском и китайском: те же 30
утверждений, тот же подсчёт, разбор с Олей на языке человека.

Механизм языков уже есть: язык теста включается сам, когда появляется
`src/content/values/texts/<код>.ts` и непустая локаль сайта
(`scripts/values-test-languages.js`); пререндер, hreflang и sitemap
подхватывают его без ручных правок.

## Решения владельца (13.10.2026)

- Порядок: сначала тест ценностей, затем калькулятор Human Design —
  отдельной спекой. Общая основа (переключатель языка, проверки текстов)
  делается здесь.
- Все шесть языков выходят одним выкатом.
- Перевод — прямо с русского (`ru.ts`), по исполнителю на язык; отклонены
  перевод через английский (два шага, смысл уплывает дважды) и скрипт через
  API (в лендинге его нет, ключа в окружении нет).
- Носителей языка для вычитки нет: качество держат независимая вычитка,
  слепая разметка утверждений на каждом языке и механические проверки.

## Границы

**Входит:** тексты теста на en, es, de, fr, pt, zh; переключатель языка и
баннер языка на странице теста; ссылка на тест со страниц Оли на шести
языках; сообщение Оле на языке страницы; проверки текстов для нерусских
языков; проверка приватности каждой языковой версии.

**Не входит:** новые утверждения и изменения подсчёта; калькулятор Human
Design (следующая спека; переключатель здесь сразу умеет вести и на него,
пока он только русский); кабинет — язык доезжает параметром `?lang=` из
ссылки (`src/lib/appUrl.ts`), кабинет передаёт его в каждом запросе к чату.

## Перевод

**Источник** — `src/content/values/texts/ru.ts`. Утверждения в нём свои, по
мотивам теории Шварца, не пересказ PVQ (проверено слепой разметкой);
переводятся они, а не официальные переводы PVQ — лицензионный вопрос
официальных переводов нас не касается.

**Правила для всех языков:**
- утверждение — портрет «этот человек» без рода, одно предложение, живой
  разговорный регистр языка («This person…», «A esta persona…», «Dieser
  Person…», «Pour cette personne…», «Para esta pessoa…», «这个人…»);
- обращение к читателю во вступлении, вопросах и ответах, результате:
  en — you; es — usted; de — Sie; fr — vous; pt — безличная форма,
  европейский португальский, как весь pt сайта; zh — 你;
- глоссарий: десять ценностей и две оси — одно слово на язык во всех
  текстах (утверждения, описания, круг, сообщение Оле); названия —
  устоявшиеся в литературе по Шварцу на этом языке (в en — Self-Direction,
  Stimulation, Hedonism, Achievement, Power, Security, Conformity, Tradition,
  Benevolence, Universalism);
- ограничения русского текста сохраняются: без цен и валют, эмодзи и слова
  «агент» (и его переводов в значении ассистента); Linkeon не переводится;
  никаких заявлений о валидности, официальности или клинической пригодности,
  кроме отрицания; оговорка «самопознание, не клиническая методика»;
- заголовок и описание страницы — с поисковыми словами языка («Schwartz
  values test», «test de valores de Schwartz» и т. п.).

**Порядок работы на каждом языке:**
1. Перевод с `ru.ts` по правилам выше.
2. Вычитка: отдельный исполнитель видит русский текст и перевод, правит
   смысл, естественность и глоссарий.
3. Слепая разметка и сверка с PVQ — как в Task 6 плана русского теста:
   новый проверяющий видит только 30 переведённых утверждений, без ключа,
   относит каждое к одной из десяти ценностей с уверенностью и сравнивает с
   формулировками PVQ-40, PVQ-21 и PVQ-RR. Порог тот же: все 30 — своя
   ценность, уверенность high, без пересказа PVQ. Утверждение мимо порога
   переписывается и проверяется новым проверяющим; не больше трёх кругов,
   оставшиеся спорные — владельцу вместе с вариантами. Для английского
   сверка с PVQ особенно важна: оригиналы PVQ англоязычные.

## Изменения в коде

- **Тексты:** `src/content/values/texts/{en,es,de,fr,pt,zh}.ts` по типу
  `ValuesTexts`.
- **Переключатель языка** (`pathForLanguage`, `src/i18n/urlLanguage.ts`): с
  `/tests/values/` и `/calculators/human-design/` — на ту же страницу другого
  языка, если она у него выпущена (`hasValuesTest` / `hasHdCalculator`),
  иначе на главную этого языка — как у страниц ассистентов.
- **Баннер языка** (`LanguageBanner`) — на странице теста; адрес он строит
  тем же `pathForLanguage`. Комментарий «тест пока только по-русски» в
  `ValuesTestPage.tsx` убирается.
- **Сообщение Оле:** список ценностей — через `Intl.ListFormat` языка
  страницы (`type: 'conjunction'`) вместо склейки «, … и …» в
  `src/lib/valuesDraft.ts`: в китайском «、» и «和» без пробелов, в
  остальных — запятые и союз языка. Регистр слов в сообщении — по правилам
  языка; лимит ссылки (600 знаков) проверяется на каждом языке.
- **Ссылки со страниц Оли:** кнопка «пройти тест» (`heroLink`) на шести
  языках, как в `src/content/assistants/pages/ru/olia.ts`; показывается,
  только если тест на этом языке выпущен.
- **Проверки текстов** (`src/content/values/texts.test.ts`):
  - для всех нерусских — нет кириллицы и ₽; ключи и подстановки — как у
    русского;
  - у китайского свои пределы длины — примерно вдвое короче, по образцу
    страниц ассистентов (`packs.test.ts`: zh 40–120 вместо 100–180);
  - вместимость подписи в круг считается по ширине знака: иероглиф — 1 em,
    остальные — 0,62 em, как сейчас;
  - правила рода и регистра остаются только для `ru`.
- **Приватность:** Вебвизор и карта кликов уже выключаются для каждой
  языковой версии (`scripts/prerender.mjs`, подстановка в HTML страницы),
  пиксель VK отсекается по разобранному маршруту (`src/main.tsx`).
  Добавляется проверка: пререндер всех семи версий страницы теста — без
  `webvisor:true` и `clickmap:true`.

## Аналитика

Цели те же — `values-test-start`, `values-test-complete`,
`values-test-to-olia` — на всех языках; язык виден по адресу страницы
(`/en/tests/values/` и т. д.). Новых целей не нужно.

## Проверки и выкат

**До выката:** тесты лендинга и пререндер на тестовой ноде; в пререндере —
семь версий страницы и кластер hreflang из семи языков, sitemap со всеми
семью адресами. Скриншоты английской и китайской версий (вступление,
вопрос, результат) — владельцу на просмотр, как было с русской.

**Выкат:** `LANDING_ONLY=1 bash scripts/deploy.sh` с OK владельца. Пока
маршрут тестовая нода → прод недоступен (с 12.10.2026), выкат с ноды идёт
только обходом через релей — тоже с OK владельца.

**После выката, на проде:** живой проход на английском и китайском — тест,
«обсудить с Олей», вход служебным аккаунтом, сообщение в поле Оли на языке
страницы, ответ Оли на том же языке; Вебвизор, карта кликов и пиксель VK
выключены на `/en/tests/values/` и `/zh/tests/values/` (по HTML и по
запросам в браузере), на главной — включены (проверка не слепая).

## Риски

- **Длина немецкого и французского.** Описания ценностей ограничены 420
  знаками; русские — 192–255, переводы длиннее на 20–30 %. Пределы не
  поднимаются: переводчик укладывается в них.
- **Оля отвечает не на языке страницы.** По коду язык доезжает; проверяется
  живым проходом. Если нет — правка в кабинете отдельной задачей.
- **Китайский без носителя.** Вычитка и слепая разметка снижают риск, но не
  убирают; при появлении носителя — показать ему тексты.
